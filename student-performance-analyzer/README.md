📊 Student Performance Analyzer

A Python-Based Academic Performance Analysis Tool

📌 Project Overview

Student Performance Analyzer is a beginner-friendly Python application designed to evaluate students' academic performance. It calculates average marks, identifies the highest and lowest scores, and automatically assigns grades.

🎯 Objectives

- Simplify academic performance evaluation.
- Automate average and grade calculations.
- Practise Python programming concepts.
- Generate an easy-to-understand performance report.

✨ Key Features

- Student name input
- Subject-wise marks collection
- Automatic average calculation
- Grade classification
- Highest and lowest marks identification
- Input validation

🛠️ Technologies Used

- Python 3
- Functions
- Conditional Statements
- Loops
- Lists

⚙️ How It Works

1. Enter the student's name.
2. Enter marks for four subjects.
3. The program calculates the average.
4. It identifies the highest and lowest marks.
5. It displays the final performance report.

💡 Learning Outcomes

Through this project, I practised Python functions, loops, conditional logic, lists and basic problem-solving.
